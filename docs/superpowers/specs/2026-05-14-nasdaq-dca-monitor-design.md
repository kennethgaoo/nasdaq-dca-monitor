# 纳斯达克100定投监控工具 — 设计文档

## 概述

为南方016452基金（QDII，跟踪纳斯达克100指数）定投者设计的量化监控工具。每日自动抓取纳指数据，从多维度计算技术指标，综合评分后给出明确的日定投金额建议（¥100~200）。

## 技术架构

```
纯前端 (HTML/CSS/JS)  ←HTTP→  Python Flask Backend  ←yfinance→  免费金融数据源
  - Chart.js 图表                      |
  - 响应式卡片布局              指标计算引擎
  - 移动端友好                   评分决策引擎
```

- **后端**：Python Flask，提供 REST API
- **前端**：单页 HTML + CSS + JS，Chart.js 渲染图表
- **数据源**：全部通过 `yfinance` 免费获取（`^NDX` 指数数据、`^VIX` 波动率数据）
- **部署方式**：本地运行 Python 服务

## 数据获取

| 数据项 | 来源 | 频率 | 用途 |
|--------|------|------|------|
| ^NDX 日线(OHLCV) | yfinance | 每次请求拉取最近1年 | 所有价格衍生指标 |
| ^VIX 日线 | yfinance | 每日 | 市场情绪维度 |

API 端点：
- `GET /api/data` — 返回完整指标数据和评分结果

## 指标体系

### 1. 趋势跟踪维度（权重 30%）

| 指标 | 计算方法 | 信号逻辑 |
|------|----------|----------|
| 均线位置 | 当前价 vs MA20/50/200 | 价格在MA之上为正，越远越负（偏离过大需回归） |
| MACD | 标准 MACD(12,26,9) | MACD柱为正/负，判断趋势方向 |
| ADX | 14周期 | >25 趋势强，<20 趋势弱 |

### 2. 动量维度（权重 20%）

| 指标 | 计算方法 | 信号逻辑 |
|------|----------|----------|
| RSI(14) | 标准 RSI | <30 超卖（加仓），>70 超买（减仓） |
| ROC | (今收-N日前收)/N日收 × 100 | 极端正值减仓，极端负值加仓 |
| Stochastic(14,3) | %K 和 %D | <20 超卖，>80 超买 |

### 3. 波动率维度（权重 15%）

| 指标 | 计算方法 | 信号逻辑 |
|------|----------|----------|
| Bollinger %B | (price - lower) / (upper - lower) | <0 超卖，>1 超买 |
| ATR(14) | 平均真实波幅 | 高ATR = 波动大，需谨慎 |
| VIX | 直接取值 | >30 恐慌（可能见底），<15 贪婪（可能见顶）|

### 4. 估值偏离维度（权重 20%）

| 指标 | 计算方法 | 信号逻辑 |
|------|----------|----------|
| 距52周高点% | (高点-现价)/高点 × 100 | 越大越便宜 |
| 距52周低点% | (现价-低点)/低点 × 100 | 越大越贵 |
| 距200日均线偏离% | (现价-MA200)/MA200 × 100 | >20% 过热，< -10% 低估 |
| Z-score(20日) | (现价-20日均价)/20日标准差 | \|Z\|>2 极端 |

### 5. 市场情绪维度（权重 15%）

| 指标 | 计算方法 | 信号逻辑 |
|------|----------|----------|
| VIX 区间法 | VIX < 15 贪婪, 15-25 正常, 25-30 恐慌, >30 极度恐慌 | 恐慌时加仓，贪婪时减仓 |
| 成交量对比 | 当日量 vs 20日均量 | 异常放量配合涨跌有信号意义 |

## 评分引擎

### 单指标评分
每个原始指标值映射到 0~100 分。以 RSI 为例：
- RSI=15 → 95 分（极度超卖，强烈加仓）
- RSI=25 → 80 分
- RSI=40 → 60 分
- RSI=50 → 50 分（中性）
- RSI=65 → 30 分
- RSI=80 → 10 分（极度超买）

其他指标类似设计，使用线性插值或分段函数。

### 维度评分
每个维度内指标加权平均得到维度分（0~100）。

### 综合评分
```
总分 = 趋势×30% + 动量×20% + 波动率×15% + 估值偏离×20% + 情绪×15%
```

### 定投金额映射

| 总分范围 | 信号标签 | 建议定投金额 |
|---------|---------|------------|
| 80~100 | 强烈加仓 | ¥200 |
| 65~79  | 加仓     | ¥160~180 |
| 45~64  | 持有     | ¥100~140 |
| 25~44  | 谨慎     | ¥100 |
| 0~24   | 风险     | ¥100（或暂停）|

金额计算公式（45分以上时线性插值）：
```
金额 = 100 + (总分 - 45) / (100 - 45) × 100
```
结果取整到十位，限制在 [100, 200] 区间。

## 前端设计

### 页面布局（从上到下）

1. **状态栏**：当前日期、NDX 最新价、涨跌幅
2. **核心建议卡片**：大号字体显示"建议定投 ¥XXX"，附带信号标签颜色
3. **信号强度条**：水平进度条显示综合评分 0~100
4. **维度分解**：5 个卡片并排（或 2+3 布局），每卡显示维度名、评分、关键指标摘要
5. **价格走势图**：NDX 日线 + Bollinger Bands + MA20/50/200（可切换显示）
6. **指标详情表**：所有原始指标值汇总表
7. **历史信号趋势**：过去30天建议金额变化小图

### 配色方案
- 强烈加仓：#2563eb（蓝色）
- 加仓：#16a34a（绿色）
- 持有：#ca8a04（黄色/橙色）
- 谨慎：#ea580c（橙色）
- 风险：#dc2626（红色）
- 背景：#f8fafc（浅灰），卡片：#ffffff

## 使用流程

1. 用户运行 `python app.py`
2. 浏览器打开 `http://localhost:5000`
3. 页面自动加载最新数据并展示
4. 每次刷新页面重新拉取最新数据并计算

## 错误处理

- 数据获取失败：前端显示"数据更新中"状态，保留上次的缓存数据
- 非交易日：自动识别（成交量=0或数据无变化），沿用前一交易日信号
- API限流：yfinance 有频率限制，后端缓存当日数据减少重复请求
